# abwi binary for Windows arm64

This is a platform-specific binary package for [abwi](https://github.com/lohn/abwi).

You probably don't want to install this package directly. Instead, install the main package:

```bash
npm install -g @abwi/cli
```

For more information, see the [abwi repository](https://github.com/lohn/abwi).
